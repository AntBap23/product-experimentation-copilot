# Demo recording status

There is no current demo video. Earlier finished videos, clips, raw recordings,
narration tracks and caption assets were removed from the project because they
show an outdated application.

The owner will test the updated public app before requesting a new recording:
[Fieldwork Analytics](https://fieldwork-analytics-demo.antbap23.workers.dev/).
Do not record or export a replacement until that request arrives.

The scripts and chapter descriptions in this folder are retained as **legacy
references**. They target an earlier UI and must be reviewed and updated before
reuse. They are not a current recording workflow or evidence of the latest
hosted experience.

The app's editable PowerPoint readout is a separate feature and remains
available in **Experiments**. See the [main README](../../README.md) and
[workspace guide](../analytics-workspace.md) for the current experience.
